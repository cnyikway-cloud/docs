Linux (Ubuntu/Debian) on Fanless Industrial PCs: Chipsets and Known Issues

Most Intel-platform fanless industrial PCs run Ubuntu and Debian out of the box. This guide lists which chipsets are safest, which drivers need attention (serial, watchdog, GPIO, TPM), and the setup steps we recommend before deployment.

Quick answer

Intel-based fanless IPCs have first-class Linux support: mainline kernels include the graphics, Ethernet (igc/igb/e1000e), NVMe and USB stacks those boards use. Deploy an LTS release (Ubuntu 22.04/24.04 LTS or Debian 12), and spend your integration effort on the board-specific items: serial ports, watchdog, GPIO and TPM.

Board-specific items to configure

  • Serial ports: onboard COM ports usually appear as /dev/ttyS* handled by serial8250. RS-422/485 mode switching is done by DIP switch (hardware) rather than software on most Yikway boards — set it before boot.
  • Watchdog: the Intel PCH watchdog exposes as /dev/watchdog via the itco_wdt module. Load it at boot and feed it with systemd:
# /etc/systemd/system.conf
RuntimeWatchdogSec=15s
RebootWatchdogSec=2min
  • GPIO: exposed via gpiod tools on modern kernels. Pin mapping differs per board model — request the GPIO table from the manufacturer.
  • TPM 2.0: works with the in-kernel tpm_crb driver; enable in BIOS first. Needed for full-disk encryption key sealing.
  • Real-time needs: for deterministic cycles use PREEMPT_RT patched kernels (Ubuntu RT or Debian's linux-image-rt); most vision and data-logging workloads do not need RT.

Deployment checklist

  1. Flash latest BIOS from the manufacturer before imaging.
  2. Install LTS; disable unattended suspend/hibernate — industrial units run 24/7 headless.
  3. Verify watchdog feeds and test an actual hang-recovery before rack installation.
  4. Pin the kernel version you validated; avoid auto major upgrades mid-project.

Frequently Asked Questions

Do fanless industrial PCs need special Linux drivers?

The core platform (graphics, Ethernet, NVMe, USB) uses mainline kernel drivers with no vendor blobs. Board extras like GPIO, watchdog and RS-485 mode switching need model-specific documentation but generally work with in-kernel modules such as itco_wdt and gpiod.

Which Ubuntu version should I install on an industrial PC?

Use the current LTS (22.04 or 24.04) and stay on it for the project lifetime. LTS kernels receive five years of security updates, which matches industrial maintenance cycles better than interim releases.

Why does my serial port not appear as /dev/ttyS0?

Serial port numbering follows PCI/ACPI enumeration order and can differ from the silkscreen labels. Check `dmesg | grep tty` or `serial8250` registration messages, and confirm the COM port is enabled (not redirected to pin-header use) in BIOS.
