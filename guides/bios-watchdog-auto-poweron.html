BIOS Setup Guide: Watchdog Timer, Auto Power-On and TPM Configuration

Three BIOS features matter most for unattended industrial PCs: the hardware watchdog, auto power-on after power loss, and TPM for security. This guide shows where to find them and how to combine BIOS with OS-level settings.

Quick answer

For a 24/7 unattended IPC, set Restore AC Power Loss = Power On (so the machine boots after any outage), enable the hardware watchdog and feed it from the OS, and enable TPM 2.0 if you use disk encryption. BIOS menu names vary by board generation, but the functions below exist on every Yikway board.

Use Power On, not Last State, when the machine must always come back after a blackout — Last State will not start a machine that was soft-shutdown when power died.

Hardware watchdog

The PCH watchdog reboots the board if the OS stops feeding it. Enable it in BIOS (often Watchdog Timer / WDT under Advanced), then feed it from Linux:

# Test: the system must reboot within the timeout if this stops
sudo modprobe itco_wdt
echo V | sudo tee /dev/watchdog   # feeds once; keep a daemon feeding it
# systemd: RuntimeWatchdogSec=15s in /etc/systemd/system.conf

Windows equivalents use the vendor watchdog service; ask for the driver package for your board model.

TPM 2.0

  • Enable under Security > TPM / Security Device. It appears to Linux via tpm_crb and to Windows as a standard TPM 2.0 device.
  • With BitLocker or LUKS, TPM-bound keys let the machine boot unattended while keeping the disk encrypted — essential when IPCs are deployed at customer sites.
  • After clearing the TPM, re-seal keys; a cleared TPM will not release old secrets.

One more setting people forget

Disable C-States or deep idle packages only if you measured latency jitter that matters; otherwise leave power management at defaults — fanless thermal designs assume idle states work.

Frequently Asked Questions

How do I make an industrial PC start automatically after a power cut?

Set 'Restore AC Power Loss' (sometimes called 'After Power Failure' or 'State After G3') to Power On in BIOS. Combined with the hardware watchdog, the machine survives both outages and OS crashes without on-site intervention.

What is the difference between a BIOS watchdog and a software watchdog?

The BIOS/hardware watchdog runs independently of the OS: if the kernel hangs so badly that userspace cannot feed the timer, the board still resets. Software-only watchdogs (like systemd's) cannot recover from a full kernel hang, so for unattended IPCs use the hardware one fed by the OS.

Can RTC alarm power on the machine at a scheduled time?

Yes. Enable 'Wake by RTC' or 'RTC Alarm' in BIOS and set the date/time (many boards support daily alarms). Note the RTC uses system time, so after long power-off periods verify the CMOS battery keeps time correctly.
